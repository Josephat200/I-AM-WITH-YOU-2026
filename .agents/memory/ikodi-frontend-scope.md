---
name: IKODI frontend-only scope
description: The user's scope boundary for development of the IKODI sponsorship portal.
---

For the IKODI Sponsorship & Scholarship Management System, build frontend work only unless the user explicitly broadens the scope. Do not modify the backend, database, or authentication.

**Why:** the user explicitly requested “only the frontend.”

**How to apply:** use the attached backend structure and workflow diagram as requirements context for the frontend, not as authorization to implement server-side features.
